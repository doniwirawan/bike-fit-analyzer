What's new

    Installing it

    1. Tap the download button on your phone.
    2. Open the file when it finishes. If Android asks, allow your browser to install apps. You only do this once, for apps that don't come from Google Play.
    3. Tap Install.

    Updating

    Download the new version and install it over the old one. Your saved results stay, because every version is signed with the same key. Don't uninstall first: uninstalling deletes your saved results.

    To check whether you're up to date, open About in the app and tap Check for updates. The app has no internet permission, so it can't check by itself. The button opens this page in your browser with your version number, and the page compares it with the latest one.
